# Pumpkin Season — Build 1

A mobile-first cozy autumn farming game prototype focused on direct world interaction.

## Core interactions
- Tap the pumpkin seed bag to enter planting mode.
- Tap an empty garden plot to plant a pumpkin.
- Tap the watering can to enter watering mode.
- Tap a growing crop to water it.
- Tap a mature pumpkin to harvest it.
- Tap the shipping crate to ship harvested pumpkins for coins.
- Tap the farmhouse to sleep and advance to the next day.
- Tap the basket to inspect harvested pumpkins and remaining seeds.

## Visual direction
The build uses small, local SVG art assets for the farm, buildings, crops, tools, and UI textures. The scene is deliberately fixed and compact for mobile, with object interactions instead of a permanent bottom action bar.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload the contents of the folder to a repository and enable GitHub Pages. All game assets are local, while the page optionally loads its display fonts from Google Fonts when the device has internet access.
