# Pumpkin Patch

A mobile-first autumn life-sim / fall festival browser game.

## Run
Open `index.html` in a browser, or deploy the repository to GitHub Pages / Cloudflare Pages.

## Current build
- Mobile-first game shell
- Farm plots
- Pumpkin seeds
- Plant / water / harvest loop
- Money system
- House
- Journal
- Forest
- Fall festival
- Four festival interactions
- Day progression
- Local save data
